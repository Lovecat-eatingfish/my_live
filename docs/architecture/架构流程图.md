## 十、发号器工作原理

```mermaid
flowchart TB
    subgraph local["内存（每业务一个BO）"]
        direction LR
        SEQ["LocalSeqIdBO 有序<br/>AtomicLong currentNum<br/>currentStart / nextThreshold"] -->|"用量>75%"| ASYNC["异步刷段"]
        UNSEQ["LocalUnSeqIdBO 无序<br/>整段shuffle打乱<br/>ConcurrentLinkedQueue"] -->|"队列剩余<25%"| ASYNC2["异步刷段"]
    end

    ASYNC --> SEM["Semaphore(1) 单飞<br/>同一号段只允许一个刷段线程"]
    ASYNC2 --> SEM
    SEM --> CAS["DB乐观锁CAS占段"]
    CAS --> SQL["update t_id_generate_config<br/>set next_threshold=next_threshold+step,<br/>current_start=current_start+step,<br/>version=version+1<br/>where id=? and version=?"]
    SQL -->|成功| LOAD["载入新号段到内存"]
    SQL -->|失败| RETRY["重试3次 tryUpdateMySQLRecord"]
    SEQ -->|getSeqId| OUT1["incrementAndGet 发号"]
    UNSEQ -->|getUnSeqId| OUT2["queue.poll() 发号"]
```

## 附：核心缓存 Key / MQ Topic 速查

| 类别 | Key / Topic | 用途 |
|---|---|---|
| 路由 | `qiyu:live:im:bind:ip:{appId}:{userId}` TTL 30s | 用户连在哪台 Netty 机器 |
| 登录 | `{app}:account:{token}` TTL 30天 | token → userId |
| 封禁 | `qiyu:live:ban:account/mute:{userId}` | 网关403 / 弹幕禁言 |
| 幂等 | `gift:consume:{uuid}` TTL 5min | 送礼消费去重 |
| 锁 | `{prefix}balance_lock:{userId}` TTL 2s | 扣款串行化 |
| 排行 | `qiyu-live-rank:gift:anchor:{yyyyMMdd}` / `gift:room:{roomId}` / `heat:room` | ZSET 三榜 |
| 风控 | `risk:word:version` 版本号懒重建 | 敏感词 trie 热更新 |
| MQ | `send_gift` / `UserExpChangeTopic` / `VideoTranscodeTopic` / `QIYU_LIVE_IM_BIZ_MSG_TOPIC` / `CACHE_ASYNC_DELETE_TOPIC` | 削峰/经验/转码/弹幕/缓存双删 |
